## Synchronization Protocol

To ensure all profiles and repositories stay completely up to date whenever a new technology is introduced:
1. **Audit & Log**: When a project adds a dependency (e.g. `npm install <pkg>` or `pip install <pkg>` or `flutter pub add <pkg>`), add it immediately to its corresponding category above.
2. **Project README Sync**: Check the project's root `README.md` to ensure the new tool is documented under its "Tech Stack" or "Built With" section.
3. **Profile Badge / Stack Sync**: If the technology represents a significant new stack pillar, update the master profile `README.md` badges or About Me skills line, ensuring existing badges are preserved and duplicates are avoided.
